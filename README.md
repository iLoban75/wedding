# Свадебное приглашение Анны и Максима

Сайт-приглашение: гость открывает ссылку, вводит свой код (или код подставляется из ссылки) — и видит конверт и персональное приглашение именно для него.

## Как это устроено

- Сайт статический (HTML, CSS, JS), хостится бесплатно на GitHub Pages.
- Приглашения гостей лежат в папке `data/` **в зашифрованном виде**. Ключ — это код гостя, поэтому без кода приглашение никто не прочитает, даже если откроет репозиторий.
- Список гостей и их коды хранятся в `private/guests.source.json`. **Эта папка в публичный репозиторий не попадает** (она в `.gitignore`) — не загружайте её вручную на GitHub.

## Как добавить гостей

1. Откройте `private/guests.source.json` и добавьте гостя по образцу:

   ```json
   {
     "id": "g002",
     "code": "",
     "addressee": "Ольга и Игорь",
     "greeting": "Дорогие Ольга и Игорь!",
     "seats": 2,
     "note": "Личная приписка (можно оставить пустой)."
   }
   ```

   - `id` — любое уникальное название;
   - `code` — оставьте пустым, код создастся автоматически (или впишите свой: минимум 10 латинских букв и цифр);
   - `addressee` — короткая подпись для конверта;
   - `seats` — сколько мест забронировано.

2. Запустите сборку: `node build.mjs` (нужен Node.js 18+).
   Скрипт выдаст каждому гостю код и готовую ссылку и обновит папку `data/`.
3. Загрузите на GitHub обновлённую папку `data/`.

## Как посмотреть у себя на компьютере

Откройте папку проекта в терминале и выполните `npx serve .`, затем откройте показанный адрес (обычно http://localhost:3000). Просто двойной клик по `index.html` не сработает: браузер не даёт читать файлы с данными.

## Что где менять

- `js/config.js` — дата, место, программа дня, дресс-код, контакты, срок ответа.
- `css/style.css` — цвета и оформление (переменные в самом начале файла).
- `index.html` — структура страниц.

## Ответы гостей («приду / не приду»)

Статичный сайт сам ничего не хранит, поэтому ответы отправляются во внешнюю форму. Самый простой вариант — Formspree (formspree.io, есть бесплатный тариф): создайте форму, скопируйте её адрес вида `https://formspree.io/f/xxxxxxx` и вставьте в `js/config.js` в поле `rsvp.endpoint`. Ответы будут приходить вам на почту. Пока поле пустое, сайт работает в демо-режиме и ничего не отправляет.

## Публикация на GitHub Pages

1. На github.com создайте репозиторий (например, `wedding`), тип **Public**.
2. Загрузите файлы: `index.html`, папки `css`, `js`, `data`. Папку `private` не загружайте.
3. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/wedding/`.
5. Впишите этот адрес в поле `siteUrl` файла `private/guests.source.json` и снова запустите `node build.mjs` — ссылки для гостей обновятся.
